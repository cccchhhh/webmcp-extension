# 中英文界面支持

日期：2026-09-18。版本：0.2.2。

## 改动

- Settings 新增“界面语言 / Interface language”，支持简体中文与 English，默认简体中文。
- 语言保存在本机 `chrome.storage.local` 的 `webmcp.uiLocale` 字段；启动恢复并监听其他侧栏的修改。存储失败保留原语言并提示重试。
- 工具、历史、参数表单、共享、模型配置、远程连接、Help 和 AIChat 使用本地翻译表，覆盖提示、状态、占位和无障碍标签。同步更新文档语言与标题。
- 切换只重新渲染界面，不重建聊天 runtime，不修改工具授权或模型配置。用户/模型正文、工具名称和描述、参数与原始结果保留原文。未知外部错误保留原始信息。
- 没有新增依赖，也没有修改后台执行或桥接协议。

## 验证

`npm run check`、`npm test`、`npm run package:extension`、`npm run test:extension` 通过。13 个测试文件、112 项测试通过。

新增 7 项测试覆盖：切换与持久化、文档语言和无障碍标签、输入草稿保留、重开恢复、多侧栏同步、无效值回退、存储读写失败、正文与工具内容不被翻译、帮助/模型/桥接英文覆盖、动态工具数量及错误消息。

按用户手动验证偏好，本轮未运行浏览器截图或浏览器闭环；现有浏览器报告为之前版本的记录。建议重新加载扩展后，在 Settings 切换 English，依次查看 Tools、AIChat、Help 与设置；填写未发送消息后切换语言，确认草稿保留；关闭再打开侧栏确认语言恢复。
